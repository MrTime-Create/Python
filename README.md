# 🐍 สอน Python ครบทุกบท (Python Learning)

🌐 **Live site:** https://MrTime-Create.github.io/Python/

เว็บไซต์สอน Python ตั้งแต่พื้นฐานจนถึงขั้นสูง พร้อมตัวอย่างโค้ดและ **Playground สำหรับทดสอบโค้ด** ได้ทันทีในเบราว์เซอร์

## 📚 บทเรียน (22 บท)

1. แนะนำ Python และการติดตั้ง
2. ตัวแปรและชนิดข้อมูล
3. ตัวดำเนินการ
4. โครงสร้างควบคุม (if/elif/else)
5. ลูป (for/while)
6. ฟังก์ชัน
7. โครงสร้างข้อมูล (List, Tuple, Set, Dict)
8. สตริง
9. โมดูลและแพ็กเกจ
10. การจัดการไฟล์
11. การจัดการข้อผิดพลาด
12. OOP - คลาสและอ็อบเจ็กต์
13. การสืบทอดและพหุรูป
14. Comprehensions
15. Lambda และฟังก์ชันเชิงฟังก์ชัน
16. Decorators และ Generators
17. Regular Expressions
18. วันที่และเวลา
19. JSON และ API
20. การทดสอบ (unittest/pytest)
21. Virtual Environment และ pip
22. Concurrency (Threading/Async)
