# บทที่ 1: แนะนำ Python และการติดตั้ง

## Python คืออะไร?

Python เป็นภาษาโปรแกรมมิ่งระดับสูง (high-level) ที่อ่านง่าย เขียนง่าย และใช้งานได้หลากหลาย ตั้งแต่เว็บ แอป วิทยาศาสตร์ข้อมูล ไปจนถึง AI

### จุดเด่น
- ไวยากรณ์อ่านง่ายเหมือนภาษาอังกฤษ
- มีไลบรารีมาตรฐานและแพ็กเกจภายนอกมากมาย
- ข้ามแพลตฟอร์ม (Windows, macOS, Linux)
- คอมมูนิตี้ขนาดใหญ่

### การติดตั้ง
ดาวน์โหลดจาก https://www.python.org/downloads/ แล้วติดตั้ง เลือก "Add Python to PATH"

ตรวจสอบการติดตั้ง:
```bash
python --version
# หรือ
python3 --version
```

### Hello, World!
```python
print("Hello, World!")
print("สวัสดี Python!")
```

### โหมดโต้ตอบ (REPL)
เปิดเทอร์มินัลแล้วพิมพ์ `python` จะเข้าสู่โหมดโต้ตอบ ลองพิมพ์:
```python
>>> 2 + 3
5
>>> print("hi")
hi
```

### รันไฟล์ .py
สร้างไฟล์ `hello.py` แล้วรัน:
```bash
python hello.py
```
